# Lollipop Landing Page

Static marketing site for Lollipop Locs, built with Next.js App Router, JavaScript, and Tailwind CSS.

## Run & Operate

- `npm install --legacy-peer-deps` — install dependencies
- `npm run dev` — start the dev server (defaults to port 3000; set `PORT` to override)
- `npm run build` — build the static export into `out/`
- `npm run start` — serve the production build (defaults to port 3000)

## Stack

- Node.js 24, JavaScript
- Next.js 16 (static export)
- Tailwind CSS 4
